# `String::as_mut_vec`

**Level:** reference · for working programmers

**One line:** The underlying `Vec<u8>`, mutably — `unsafe`, because you can resize it and must leave valid UTF-8 behind.

```text
pub const unsafe fn as_mut_vec(&mut self) -> &mut Vec<u8>
```

Stable since **1.0.0**. `unsafe` — the caller carries the invariant described below. Usable in a `const` context.

This is the most powerful and most dangerous view of a `String`. Unlike [`as_mut_str`](../string_as_mut_str/README.md), the `Vec` can grow, shrink and be written arbitrarily — and the `String` is required to hold valid UTF-8 when the borrow ends.

The contract is exactly that: **valid UTF-8 by the time the `&mut Vec<u8>` is dropped.** In between, anything goes.

Almost every real use has a safe equivalent — [`push_str`](../string_push_str/README.md), [`retain`](../string_retain/README.md), [`truncate`](../string_truncate/README.md), [`replace_range`](../string_replace_range/README.md). The honest cases are decoding into a buffer whose validity you establish yourself, and byte-level work that would otherwise need a copy out and back.

Breaking the invariant is undefined behaviour, not mojibake.

## Example

<!-- source:string_as_mut_vec -->
*[`string_as_mut_vec.rs`](examples/string_as_mut_vec.rs) in full — pasted here by `tools/run_examples.py` from the file CI compiles and runs.*

```rust
fn main() {
    let mut s = String::from("hello");

    // Sound: ASCII appended to ASCII is still valid UTF-8.
    unsafe { s.as_mut_vec().extend_from_slice(b" world") }
    println!("{s:?}");

    // Sound: truncating at a boundary we checked.
    let mut wide = String::from("héllo");
    let cut = wide.floor_char_boundary(3);
    unsafe { wide.as_mut_vec().truncate(cut) }
    println!("{wide:?}");

    // The safe equivalents of both.
    let mut safe = String::from("hello");
    safe.push_str(" world");
    safe.truncate(5);
    println!("{safe:?}");

    // Why the truncate above needed a boundary check.
    let check = "héllo";
    println!("boundary at 2? {}  at 3? {}",
             check.is_char_boundary(2), check.is_char_boundary(3));
}
```
