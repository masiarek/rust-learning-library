# `str::trim_left`

**Level:** reference · for working programmers

> **Deprecated since Rust 1.33 — use [`str::trim_start`](../str_trim_start/README.md) instead.** The page is here because the name is still in code written before it moved, and it still compiles; a new call site should not use it.

**One line:** The pre-1.33 name for [`trim_start`](../str_trim_start/README.md).

```text
pub fn trim_left(&self) -> &str
```

Stable since **1.0.0**.

Renamed because "left" describes a position on screen and the method describes a position in the bytes. For right-to-left scripts the two are opposite, so the old name was actively misleading; `start` and `end` are unambiguous in every script.

Identical behaviour — delete `left`, write `start`.

## Example

```rust
#![allow(deprecated)]

fn main() {
    let s = "  padded  ";
    println!("{:?}", s.trim_left());
    println!("{:?}", s.trim_start());
    println!("identical: {}", s.trim_left() == s.trim_start());
}
```
