# `str::rsplit_once`

**Level:** reference · for working programmers

**One line:** Splits at the **last** match into exactly two pieces, or `None` — the tool for stem-and-extension.

```text
pub fn rsplit_once<P: Pattern>(&self, delimiter: P) -> Option<(&'_ str, &'_ str)>
where
    for<'a> P::Searcher<'a>: ReverseSearcher<'a>,
```

Stable since **1.52.0**.

Same shape as [`split_once`](../str_split_once/README.md), anchored at the other end. The tuple is in reading order — `(before, after)` — which is the difference from [`rsplitn`](../str_rsplitn/README.md), whose iterator yields the last field first.

`"a.b.c".rsplit_once('.')` is `Some(("a.b", "c"))`.

Use it whenever the delimiter can appear more than once and it is the last one that matters: a file extension, `host:port`, the final path segment. For filenames specifically, [`Path`](../../../04_Files/path_and_pathbuf/README.md) knows the platform rules this does not.

## Example

<!-- source:str_rsplit_once -->
*[`str_rsplit_once.rs`](examples/str_rsplit_once.rs) in full — pasted here by `tools/run_examples.py` from the file CI compiles and runs.*

```rust
fn main() {
    for name in ["a.b.c", "noext", ".hidden", "trailing."] {
        println!("{name:<10?} -> {:?}", name.rsplit_once('.'));
    }

    // Reading order, unlike rsplitn.
    let path = "/usr/local/bin/rustc";
    println!("{:?}", path.rsplit_once('/'));
    println!("{:?}", path.rsplitn(2, '/').collect::<Vec<&str>>());

    // host:port, where the host may itself contain colons.
    for addr in ["example.com:8080", "::1:9000"] {
        println!("{addr:<18?} -> {:?}", addr.rsplit_once(':'));
    }
}
```
