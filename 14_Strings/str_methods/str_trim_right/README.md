# `str::trim_right`

**Level:** reference · for working programmers

> **Deprecated since Rust 1.33 — use [`str::trim_end`](../str_trim_end/README.md) instead.** The page is here because the name is still in code written before it moved, and it still compiles; a new call site should not use it.

**One line:** The pre-1.33 name for [`trim_end`](../str_trim_end/README.md).

```text
pub fn trim_right(&self) -> &str
```

Stable since **1.0.0**.

Renamed alongside `trim_left`, for the same reason: the end of a string is a byte position, not a screen position.

Identical behaviour — delete `right`, write `end`.

## Example

<!-- source:str_trim_right -->

```rust
#![allow(deprecated)]

fn main() {
    let s = "  padded  ";
    println!("{:?}", s.trim_right());
    println!("{:?}", s.trim_end());
    println!("identical: {}", s.trim_right() == s.trim_end());
}
```
