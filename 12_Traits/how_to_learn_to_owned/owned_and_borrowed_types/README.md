# Step 3: Owned and borrowed are two different types

[How to learn `ToOwned`](../README.md) › **Step 3 of 10** · back: [Step 2 — Some types have no size](../types_with_no_size/README.md) · next: [Step 4 — `Clone` hands back `Self`](../clone_returns_self/README.md)

**Level:** 101 · a step on a learning path

**One line:** `String` and `str`. `Vec<T>` and `[T]`. `PathBuf` and `Path`. The borrowed half is the type **behind** the `&`, not the `&` itself — which is how the owned twin of `str` gets to be a different type, `String`.

## Two halves, one set of bytes

A `String` is a small, sized handle — address, capacity, length — that owns a buffer on the heap. The `str` is the bytes in that buffer. Dereference a `String` and you are looking at a `str`; borrow that, and you hold a `&str` pointing into the same buffer.

| Owned — sized, owns the buffer | Borrowed half — the type behind the `&` | What you pass around |
|---|---|---|
| `String` | `str` | `&str` |
| `Vec<T>` | `[T]` | `&[T]` |
| `PathBuf` | `Path` | `&Path` |
| `OsString` | `OsStr` | `&OsStr` |
| `CString` | `CStr` | `&CStr` |
| `Box<T>` | `T` | `&T` |

Read the table by column, not by row: the middle column is the one `ToOwned` is implemented on ([step 1](../clone_vs_to_owned/README.md)), and the right-hand column is what your functions take.

## `Deref` names the pair

Each owned type says which borrowed half it has with `impl Deref for String { type Target = str; ... }`. That one impl does three jobs you have already relied on:

- `*s` is a `str` — the checkpoint below.
- `&s` coerces to `&str` wherever a `&str` is expected, so one `fn f(name: &str)` serves every caller. That is **deref coercion**.
- `s.len()` finds `str::len`, because the dot follows `Deref` when the owned type has no such method — [step 5](../the_dot_picks_first/README.md) walks that search.

## One direction is free, the other allocates

Owned → borrowed copies nothing: the `&str` points at the `String`'s own bytes. Borrowed → owned has to build a new owner, with its own buffer — that is `to_owned`, and it is the only direction `ToOwned` covers. The way back again, owned → borrowed as a *trait*, is `Borrow`, [step 7](../borrow_the_way_back/README.md).

## Po polsku

Wersja posiadana i pożyczona to **dwa różne typy**: `String` i `str`, `Vec<T>` i `[T]`, `PathBuf` i `Path`. Pożyczona połowa to typ **za** `&`, a nie samo `&` — i właśnie dlatego „posiadany bliźniak” `str` może być innym typem, `String`.

Parę spina `Deref`: `impl Deref for String { type Target = str; }`. Dzięki temu `*s` jest typu `str`, `&String` samo zamienia się w `&str` (*deref coercion*), a `s.len()` znajduje `str::len`. Z posiadanej do pożyczonej — za darmo; z pożyczonej do posiadanej — nowa alokacja, czyli `to_owned`.
